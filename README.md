#  NeuroCiencia Interactiva (Synapse Hub)

Una plataforma web interactiva, educativa y 100% *Frontend* (Zero-Server), diseñada para acercar la neuroanatomía, la bioelectricidad y la neurotecnología al público en general. Todo el sistema está construido usando **Vanilla JavaScript, HTML y CSS**, empleando conceptos de álgebra lineal y probabilidad estructural en sus motores internos.

##  Características Principales

* 👩‍⚕️ **Dra. NeuroBot (NLP Simulado):** Un asistente virtual integrado que utiliza el cálculo de similitud vectorial para responder consultas sobre estructuras físicas del cerebro, sinapsis y tecnología BCI. *(Nota: El bot cuenta con estrictos protocolos de filtrado algorítmico que lo restringen a datos científicos comprobables, bloqueando temas no relacionados como política).*
* 🎮 **Entrenamiento Cognitivo Dinámico:** Un motor de 20 minijuegos (4 mecánicas principales escaladas en 5 niveles de dificultad) que incluyen:
    * Navegación Espacial (NeuroBot Grid)
    * Alineación de Canales (Synapse Overdrive)
    * Memoria Visual y Neuro-Trivia.
    * *Los juegos utilizan una función temporal matemática para rotar de manera automática cada 4 horas.*
* 📰 **Boletín Sináptico Diario:** Una sección de novedades científicas verídicas (neurogénesis, optogenética, interfaces BCI) que se actualizan automáticamente calculando el día del año.
* 🌍 **Soporte Bilingüe (i18n):** Cambio instantáneo de la interfaz completa, los datos y el chatbot entre Español e Inglés sin recargar la página.

##  Tecnologías Usadas
* HTML5 & CSS3 (Diseño responsivo y variables CSS).
* Vanilla JavaScript (ES6+).
* Simulación matemática de procesamiento de lenguaje natural (NLP) y codificación posicional (Positional Encoding) adaptada al frontend.
* Sin dependencias, sin bases de datos, sin servidores backend.
